# UI автотесты проекта (Sprint 5)


Данный проект содержит автоматизированные UI тесты для веб-приложения.

Тесты написаны с использованием:
- Python
- Selenium WebDriver
- Pytest
- Page Object Model (POM)

---

В рамках проекта проверяются следующие сценарии:
- Регистрация пользователя
- Авторизация пользователя
- Выход из аккаунта
- Переход в личный кабинет
- Переходы между разделами конструктора:
  - Булки
  - Соусы
  - Начинки
- Переходы по логотипу (возврат в конструктор)

---

Запуск всех тестов
- pytest
Запуск тестов из папки
- pytest tests/
Запуск конкретного теста
- pytest tests/test_constructor.py::test_go_to_constructor_by_logo
